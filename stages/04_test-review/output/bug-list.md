| B002 | F08.3 (EPUB, day/night) | minor | verified | Dark frame around the page text in day mode (found by the user's hand test of the installed v1.0.0) | Steps: open an EPUB in night mode (or with a chapter loaded at night), switch to day. | B003 | F02 (EPUB navigation) | minor | verified | Mouse wheel did nothing in EPUBs (found by the user's hand test H5 on v1.0.1) | Spec F02 lists "mouse wheel" for both formats and the shortcut table lists Ctrl+wheel for EPUB text size; only PDF had it (F02.5's criterion is PDF-only, so no EPUB test caught it). Fix (2026-10-06): wheel turns the page (one page per flick, 300 ms cool-down, also over the margins); Ctrl+wheel = text size. e2e test added; checked in the packaged app with the Carnegie EPUB. Fixed in installer **v1.0.2**. **Verified**: user confirmed on the installed 1.0.2 (2026-10-06). |
| B004 | F08.3 (EPUB, night mode) | major | verified | Night mode left the text dark and unreadable in Project Gutenberg EPUBs (found by the user with *The Adventures of Sherlock Holmes*, pg1661, on v1.1.0) | Steps: open a Gutenberg EPUB, switch to night mode. Expected: light text on the dark page. Actual: dark text on the dark page. Cause: the book's own CSS says `body { color: black; background-color: white }`; our night colour was set on `html` only, so the book's body rule beat it (the Carnegie test book sets no body colour, so no earlier test saw it). Fix (2026-10-06): book styles now force the theme colour on `body` and, in night mode, replace every text colour in the book (links keep the accent colour). New fixture `styled.epub` + e2e test that reads real screen pixels in night/day/night (fails without the fix, passes with it); checked with the real pg1661 book in both themes. Fixed in installer **v1.1.1**; **Verified**: the user confirmed on the installed 1.1.1 (2026-10-06) that night-mode text is readable. |
